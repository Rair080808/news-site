Новостной сайт «Научный прогресс»
Веб-приложение разработано на платформе Laravel 11. Представляет собой новостной портал научно-технической тематики. Пользователям предоставляется разный уровень доступа к разделам сайта в зависимости от назначенной роли.

Назначение
Система предназначена для публикации новостных статей. Обеспечивает хранение учётных записей пользователей с разграничением прав доступа по ролям, ведение справочника категорий, публикацию текстов с привязкой к автору и категории, а также управление статьями и ролями в административном разделе.

Технологии
Laravel 11 (PHP 8.3)
База данных SQLite
Eloquent ORM
Blade-шаблоны
Middleware для разграничения доступа
Структура базы данных
База данных состоит из четырёх взаимосвязанных таблиц: roles, categories, users, texts. Таблицы roles и categories являются справочными, таблица users — учётной, таблица texts — основной рабочей.
Связи и ограничения целостности
Связь	Тип	Поведение при удалении
roles → users	один-ко-многим	RESTRICT — удаление роли, назначенной пользователям, запрещено
categories → texts	один-ко-многим	RESTRICT — удаление категории, содержащей тексты, запрещено
users (автор) → texts	один-ко-многим	CASCADE — удаление пользователя удаляет его тексты
Внешние ключи являются обязательными (NOT NULL) и проиндексированы. Поле login таблицы users имеет уникальный индекс. Ссылочная целостность обеспечивается внешними ключами базы данных.

Связи реализованы в моделях Eloquent: Role, User, Category, Text (каталог app/Models). Миграции находятся в каталоге database/migrations.

Разделы сайта
Раздел	Маршрут	Описание
Главная	/	Вывод всех опубликованных статей, сортировка от новых к старым, пагинация
Категория	/category/{slug?}	Вывод статей выбранной категории, вкладки категорий
Журналист	/journalist	Форма создания статьи, список «Мои статьи»
Админ	/admin	Управление статьями и ролями пользователей
Доступ по ролям
Раздел	Пользователь (reader)	Журналист	Администратор
Главная	доступен	доступен	доступен
Категория	доступен	доступен	доступен
Журналист	запрещён (403)	доступен	доступен
Админ	запрещён (403)	запрещён (403)	доступен
Разграничение доступа реализовано с помощью Middleware CheckRole (app/Http/Middleware/CheckRole.php), зарегистрированного как алиас role в bootstrap/app.php. Применение к маршрутам выполняется в routes/web.php:

php


Route::middleware(['auth', 'role:journalist,admin'])->group(function () {
    Route::get('/journalist', ...);
    Route::post('/journalist', ...);
});

Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/admin', ...);
});
Неавторизованному пользователю Middleware возвращает перенаправление на страницу входа; авторизованному пользователю без требуемой роли возвращается ошибка 403 (resources/views/errors/403.blade.php). В шапке и подвале ссылки на разделы отображаются в зависимости от роли пользователя.

Авторизация
Авторизация выполняется по логину и паролю. Пароль хранится в базе данных в хешированном виде. Логин является уникальным. При регистрации новому пользователю назначается роль reader.

Запуск проекта
Требования: PHP 8.2 и выше, Composer.

bash


cd news-site
composer install
copy .env.example .env          # Windows
# cp .env.example .env          # Linux
php artisan key:generate
php artisan migrate:fresh --seed
php artisan serve
Приложение доступно по адресу http://localhost:8000

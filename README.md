# Новостной сайт «Научный прогресс» — Лабораторные работы №3 / №4

Веб-приложение на **Laravel 11**: новостной портал о науке и технологиях.

**Лабораторная №3** — спроектирована и настроена **база данных из четырёх
взаимосвязанных таблиц** (`roles`, `categories`, `users`, `texts`) и **отношения
Eloquent** между ними.

**Лабораторная №4** — реализовано **разграничение доступа** к разделам сайта
по ролям пользователей с помощью **Middleware**.

## Доступ к разделам по ролям (Лабораторная №4)

| Раздел | Обычный пользователь (`reader`) | Журналист | Администратор |
|---|---|---|---|
| **Главная** | ✅ | ✅ | ✅ |
| **Категория** | ✅ | ✅ | ✅ |
| **Журналист** | ❌ 403 | ✅ | ✅ |
| **Админ** | ❌ 403 | ❌ 403 | ✅ |

Реализовано через:
- **Middleware** `App\Http\Middleware\CheckRole` — проверяет роль пользователя
  (берёт имя роли из таблицы `roles` через связь `User::role()`).
- Зарегистрирован алиас `role` в `bootstrap/app.php`:
  ```php
  $middleware->alias(['role' => CheckRole::class]);
  ```
- Применение к маршрутам (`routes/web.php`):
  ```php
  Route::middleware(['auth', 'role:journalist,admin'])->group(function () {
      Route::get('/journalist', ...);
      Route::post('/journalist', ...);
  });
  Route::middleware(['auth', 'role:admin'])->group(function () {
      Route::get('/admin', ...);
  });
  ```
- Неавторизованного middleware перенаправляет на `login`; авторизованного
  без нужной роли — на страницу ошибки **403** (`resources/views/errors/403.blade.php`).
- В **шапке и подвале** ссылки на разделы показываются в зависимости от роли,
  рядом с логином отображается бейдж роли.

## Структура базы данных (4 таблицы)

| Таблица | Назначение | Роль |
|---|---|---|
| `roles` | Справочник ролей пользователей | Родительская для `users` |
| `categories` | Справочник категорий текстов | Родительская для `texts` |
| `users` | Учётные записи пользователей (логин/пароль) | Учётная |
| `texts` | Статьи (контент) | Основная рабочая |

> **Примечание.** В предыдущей лабораторной таблица статей называлась
> `articles`, теперь переименована в `texts` (поля `heading` — заголовок,
> `text` — текст), модель `Article` переименована в `Text`.

### Схема таблиц

```
roles
  PK id  INTEGER
     name       VARCHAR   (UNIQUE)     — название роли

categories
  PK id  INTEGER
     name       VARCHAR
     slug       VARCHAR   (UNIQUE)     — для маршрутов

users
  PK id        INTEGER
     login      VARCHAR   (UNIQUE)     — уникальный логин
     password   VARCHAR   (хранит bcrypt-hash)
  FK role_id    -> roles.id            (обязателен, проиндексирован)

texts
  PK id          INTEGER
     heading     VARCHAR               — заголовок
     text        TEXT                  — текст статьи
     is_published BOOLEAN              — опубликована ли
  FK category_id -> categories.id      (обязателен, проиндексирован)
  FK user_id     -> users.id           (обязателен, проиндексирован)
     created_at / updated_at           — временные метки
```

### Связи и целостность (отношения Eloquent)

| Связь | Тип | Поведение при удалении |
|---|---|---|
| `roles` → `users` | один-ко-многим (`Role::users()`, `User::role()`) | **RESTRICT** — нельзя удалить роль, назначенную пользователям |
| `categories` → `texts` | один-ко-многим (`Category::texts()`, `Text::category()`) | **RESTRICT** — нельзя удалить категорию, в которой есть тексты |
| `users` (автор) → `texts` | один-ко-многим (`User::texts()`, `Text::user()`) | **CASCADE** — удаление пользователя удаляет его тексты |

- Все внешние ключи **обязательны** (NOT NULL) и **проиндексированы**.
- `login` в `users` имеет **уникальный индекс**.
- Ссылочная целостность обеспечивается внешними ключами базы данных.

Модели: `app/Models/Role.php`, `User.php`, `Category.php`, `Text.php`.
Миграции: `database/migrations/`.

## Разделы сайта

| Раздел | Маршрут | Описание |
|---|---|---|
| **Главная** | `/` | Все опубликованные `texts` из БД, от новых к старым, пагинация |
| **Категория** | `/category/{slug?}` | Статьи одной категории из БД (по умолчанию «Технологии»), вкладки |
| **Журналист** | `/journalist` | Форма создания статьи (заголовок, категория, текст) + «Мои статьи». Только авторизованным |
| **Админ** | `/admin` | Только для администраторов (Middleware role:admin). Таблица статей (редактировать/блокировать/удалить) и форма смены ролей пользователей |

Авторизация — только по **логину и паролю**; пароль хранится хешированным;
логин уникален. При регистрации новому пользователю назначается роль **`reader`**
(в сидере есть роли admin / moderator / journalist / reader).

## Как запустить

Требуется **PHP 8.2+** и **Composer**.

```bash
cd news-site
composer install
copy .env.example .env          # Windows
# cp .env.example .env          # Linux
php artisan key:generate
php artisan migrate:fresh --seed
php artisan serve               # http://localhost:8000
```

**Тестовые аккаунты** (создаются сидером):

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | admin |
| `jurnalist` | `secret` | journalist |
| `reader` | `reader123` | reader |

# Инструкция: как проверить сайт (Лабораторная работа №2)

Есть **два способа** проверки. Выберите тот, что вам подходит.

---

## Способ 1. Быстрый — статические превью (БЕЗ установки программ)

В папке `preview/` лежат готовые HTML-страницы — они открываются в браузере
**двойным щелчком мыши**, ничего устанавливать не нужно.

📂 `news-site\preview\`

| Файл | Что показывает |
|---|---|
| `home.html` | Главная — все статьи, пагинация |
| `category.html` | Категория «Технологии» с вкладками |
| `journalist.html` | Журналист — форма создания статьи |
| `login.html` | Вход (логин + пароль) |
| `register.html` | Регистрация (логин + пароль + подтверждение) |
| `admin.html` | Админ (заглушка) |

### Как открыть
1. Откройте папку `news-site\preview\`.
2. Двойной щелчок по `home.html` — откроется в браузере по умолчанию.
3. По ссылкам внутри страниц можно ходить между разделами.

⚠️ В превью **данные не сохраняются** (это статические макеты, без сервера и базы).
Полноценная работа с базой данных и авторизацией — только через Способ 2.

## Способ 2. Полный — запустить Laravel (с базой данных, авторизацией)

Для этого нужны **PHP 8.2+** и **Composer**. Сейчас на компьютере они не найдены,
поэтому сначала их нужно установить.

### Шаг 0. Установить PHP и Composer (если ещё не установлены)

**Вариант А — отдельно:**
1. Скачайте PHP 8.2/8.3 (64-bit) с https://windows.php.net/download
   Например: `php-8.3.x-nts-Win32-vs16-x64.zip`
2. Распакуйте в `C:\php` и добавьте `C:\php` в переменную окружения PATH.
3. Скачайте Composer с https://getcomposer.org/download/ (файл `composer-setup.exe`).
4. Запустите установку Composer, укажите путь к `C:\php\php.exe`.

**Вариант Б — OpenServer (проще для студентов):**
1. Скачайте OpenServer с https://ospanel.io/download/
2. Установите и запустите; в меню выберите версию **PHP 8.2+** (Модули → PHP).
3. Composer внутри OpenServer есть в `OSPanel\modules\composer\`.

Убедитесь, что PHP работает:
```bash
php -v     # должна вывести версию PHP, например 8.3.x
composer -V
```

### Шаг 1. Установить зависимости проекта
```bash
cd news-site
composer install
```

### Шаг 2. Создать файл `.env`
```bash
copy .env.example .env      # Windows
```
```bash
php artisan key:generate    # сгенерирует ключ приложения
```

### Шаг 3. Создать базу данных с демо-данными
```bash
php artisan migrate:fresh --seed
```
Эта команда создаст таблицы `users`, `categories`, `articles`
и наполнит их тестовыми данными.

### Шаг 4. Запустить сервер
```bash
php artisan serve
```
Сайт откроется по адресу: **http://localhost:8000**

## Чек-лист проверки требований ЛР №2

После запуска проверьте по пунктам:

### 1. Общие требования
- [ ] Шапка и подвал есть на **каждой** странице (это отдельные компоненты).
- [ ] Навигация в шапке позволяет ходить между разделами: Главная, Технологии (категория), Журналист.

### 2. Создание и сохранение статей
- [ ] Откройте раздел **Журналист** (если не авторизованы — сайт попросит войти).
- [ ] Войдите: логин `admin`, пароль `admin123` (или зарегистрируйте нового пользователя).
- [ ] Заполните форму: заголовок, категория, текстовка → нажмите «Опубликовать статью».
- [ ] Появится зелёное сообщение «Статья сохранена и опубликована!».
- [ ] Перейдите на **Главную** — новая статья появилась вверху списка.
- [ ] Перейдите в раздел **Технологии** (категория) — статья появилась там тоже.

### 3. Авторизация и регистрация
- [ ] Кнопка «Регистрация» — зарегистрируйтесь с новым логином и паролем.
- [ ] Попробуйте зарегистрировать **один и тот же логин дважды** — появится ошибка
      «Пользователь с таким логином уже существует» (требование: логин уникален).
- [ ] Вход с неверным паролем — сообщение «Неверный логин или пароль».
- [ ] После входа в шапке справа виден ваш логин и кнопка «Выйти».
- [ ] Кнопка «Выйти» работает: возвращает на главную, раздел «Журналист» снова требует входа.
- [ ] (Требование про хеширование) Пароль в базе хранится в зашифрованном виде.
      Проверить можно так:
      ```bash
      php artisan tinker
      > App\Models\User::first()->password
      ```
      Вы увидите строку вида `$2y$12$...` — это bcrypt-хеш, а не сам пароль.

### 4. Главная
- [ ] Выводятся все опубликованные статьи из БД (включая новую, созданную вами).
- [ ] Сортировка: самые свежие сверху.
- [ ] Внизу есть пагинация (страницы «1 2 3 …»).
- [ ] В карточке статьи видно: заголовок, категория и автор (логин).

### 5. Категория
- [ ] В разделе «Технологии» показаны только статьи этой категории.
- [ ] Вкладки сверху позволяют переключиться на другие категории (Космос, Медицина, Физика).

### Тестовые аккаунты
| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | администратор |
| `jurnalist` | `secret` | журналист |

## Частые проблемы

| Проблема | Решение |
|---|---|
| `php` не является командой | PHP не в PATH — используйте полный путь `C:\php\php.exe` или OpenServer |
| `composer install` медленный | Нормально при первом запуске, скачиваются пакеты |
| Страница открывается без стилей | Убедитесь, что адрес http://localhost:8000, а не файл preview |
| Ошибка `target class [App\Http\Controllers\PageController] does not exist` | Убедитесь, что используется обновлённый код (PageController заменён на ArticleController) |
| Пароль «не подходит» после migrate | Запустите `php artisan migrate:fresh --seed` заново (пересоздаст пользователей) |
